# 🎯 Краткое описание проекта

## Что реализовано

Полноценное клиент-серверное приложение с авторизацией по протоколу Фиата-Шамира на C++ с Qt GUI.

### ✅ Основные функции

- **Клиент-серверная архитектура** с TCP/IP коммуникацией
- **Протокол Фиата-Шамира** для безопасной аутентификации
- **Графический интерфейс** на Qt6 для клиента
- **Регистрация пользователей** с генерацией ключей
- **Безопасное хранение** только открытых ключей на сервере
- **Нулевое разглашение** - секретные ключи не передаются по сети

### 🏗️ Архитектура

```
├── server/     # Серверное приложение (Qt Core + OpenSSL)
├── client/     # Клиент с GUI (Qt Widgets + Network)  
├── common/     # Общие криптографические классы
└── scripts/    # Скрипты сборки и запуска
```

### 🔧 Технологии

- **C++17** с использованием `using namespace std;`
- **Qt6** (Core, Widgets, Network)
- **OpenSSL** для криптографии больших чисел
- **CMake/qmake** для сборки
- **macOS** оптимизированные скрипты

### 🛡️ Безопасность

- 512+ битные криптографические ключи
- Секретные данные никогда не покидают клиент
- Использование проверенных криптографических библиотек
- Защита от основных атак

### 🚀 Запуск

```bash
# Сборка
./build_macos.sh

# Демонстрация  
./demo.sh
```
