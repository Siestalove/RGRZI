# Математические основы протокола Фиата-Шамира

## Описание протокола

Протокол Фиата-Шамира - это протокол идентификации с нулевым разглашением, позволяющий prove знание секрета без его раскрытия.

## Математический аппарат

### 1. Генерация ключей

1. **Выбор параметров**:
   - Выбираются два больших простых числа p и q (обычно ~512 бит)
   - Вычисляется модуль: `n = p × q`
   - n публикуется, p и q сохраняются в секрете

2. **Генерация ключей пользователя**:
   - Выбирается случайное секретное число s: `1 < s < n`
   - Вычисляется открытый ключ: `v = s² mod n`
   - Пара (s, v) является ключами пользователя

### 2. Процесс аутентификации

Пользователь (Prover) доказывает знание секрета s серверу (Verifier):

1. **Шаг 1**: Пользователь генерирует случайное r: `1 < r < n`
   - Вычисляет: `x = r² mod n`
   - Отправляет x серверу

2. **Шаг 2**: Сервер генерирует случайный вызов e ∈ {0, 1}
   - Отправляет e пользователю

3. **Шаг 3**: Пользователь вычисляет ответ:
   - `y = r × s^e mod n`
   - Отправляет y серверу

4. **Шаг 4**: Сервер проверяет:
   - `y² ≡ x × v^e (mod n)`
   - Если равенство верно, аутентификация успешна

### 3. Доказательство корректности

Если e = 0:
```
y² = (r × s^0)² = r² ≡ x × v^0 = x × 1 = x (mod n)
```

Если e = 1:
```
y² = (r × s^1)² = r² × s² ≡ x × v = x × s² (mod n)
```

### 4. Свойства нулевого разглашения

Протокол обладает свойством нулевого разглашения, так как:
- Злоумышленник может подделать ответ только с вероятностью 1/2
- Для повышения безопасности протокол повторяется t раз
- Вероятность обмана становится (1/2)^t

## Реализация в проекте

### Криптографические операции

Используется библиотека OpenSSL для работы с большими числами:

```cpp
// Модульное возведение в степень
BN_mod_exp(result, base, exp, mod, ctx);

// Модульное умножение  
BN_mod_mul(result, a, b, mod, ctx);

// Генерация простых чисел
BN_generate_prime_ex(prime, bits, 1, NULL, NULL, NULL);
```

### Безопасность

- Используются 512-битные числа (минимальный рекомендуемый размер)
- Криптографически стойкий генератор случайных чисел
- Секретные ключи никогда не покидают клиентское приложение
- Все вычисления выполняются локально

### Параметры системы

- Размер модуля n: 1024 бита (512 × 2)
- Размер секретного ключа s: до 1024 бит
- Количество раундов аутентификации: 1 (можно увеличить для большей безопасности)

## Преимущества протокола

1. **Нулев разглашение**: Секрет не раскрывается при аутентификации
2. **Отсутствие передачи пароля**: Исключена возможность перехвата пароля
3. **Математическая строгость**: Основан на трудности извлечения квадратного корня
4. **Минимальные требования**: Не требует хранения паролей на сервере

## Возможные атаки и защита

1. **Атака "человек посередине"**: Предотвращается использованием защищенного канала
2. **Повторная аутентификация**: Используются случайные значения r
3. **Перебор секрета**: Защищено большой длиной ключа (512+ бит)
4. **Факторизация n**: Требует разложения 1024-битного числа (вычислительно невозможно)
