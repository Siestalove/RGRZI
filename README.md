# Клиент-серверное приложение с авторизацией по протоколу Фиата-Шамира

Приложение реализует протокол идентификации Фиата-Шамира с графическим интерфейсом на Qt.

## Особенности реализации

- **Клиент-серверная архитектура**: Сервер хранит открытые ключи, клиент работает с секретными ключами локально
- **Безопасность**: Секретные ключи никогда не передаются по сети
- **Графический интерфейс**: Клиентское приложение имеет интуитивный Qt GUI
- **Кроссплатформенность**: Работает на macOS, Linux и Windows

## Сборка на macOS

### 🎯 Ваш случай: Qt 6.9.3 уже установлен через Homebrew

Если у вас Qt установлен в `/opt/homebrew/Cellar/qt/6.9.3/`:

```bash
# Быстрая сборка
export PATH="/opt/homebrew/Cellar/qt/6.9.3/bin:$PATH"
cd server && /opt/homebrew/Cellar/qt/6.9.3/bin/qmake && make && cd ../client && /opt/homebrew/Cellar/qt/6.9.3/bin/qmake && make
```

### Способ 1: Использование готовых скриптов

```bash
# Автоматическая сборка (адаптируйте под ваш Qt)
./build_qmake.sh
```

### Способ 2: Ручная сборка с указанием путей

1. **Установка переменных окружения**:
```bash
export PATH="/opt/homebrew/Cellar/qt/6.9.3/bin:$PATH"
export LDFLAGS="-L/opt/homebrew/opt/openssl/lib"
export CPPFLAGS="-I/opt/homebrew/opt/openssl/include"
export PKG_CONFIG_PATH="/opt/homebrew/opt/openssl/lib/pkgconfig"
```

2. **Сборка сервера**:
```bash
cd server
qmake server.pro
make
```

3. **Сборка клиента**:
```bash
cd ../client
qmake client.pro
make
```

### Способ 3: Использование CMake

```bash
mkdir build
cd build
cmake .. -DCMAKE_PREFIX_PATH="/opt/homebrew/Cellar/qt/6.9.3"
make
```

## Использование приложения

### Запуск сервера

1. Запустите серверное приложение:
```bash
./fiat_shamir_server
```

2. Сервер автоматически запустится на порту 12345 и создаст файл `users.json` для хранения пользователей.

### Работа с клиентом

1. Запустите клиентское приложение:
```bash
./fiat_shamir_client
```

2. **Подключение к серверу**:
   - Введите адрес сервера (по умолчанию 127.0.0.1)
   - Введите порт (по умолчанию 12345)
   - Нажмите "Подключиться"

3. **Регистрация нового пользователя**:
   - Нажмите "Зарегистрироваться"
   - Введите логин
   - Сервер сгенерирует и покажет вам секретный ключ
   - **Сохраните этот секретный ключ!** Он понадобится для входа

4. **Аутентификация**:
   - Нажмите "Войти в систему"
   - Введите ваш логин
   - Введите секретный ключ, полученный при регистрации
   - Система автоматически выполнит протокол Фиата-Шамира

## Протокол Фиата-Шамира

Приложение реализует следующий алгоритм:

1. **Генерация ключей**:
   - Сервер генерирует модуль `n = p * q` (где p, q - большие простые числа)
   - Для каждого пользователя генерируется секретный ключ `s` и открытый ключ `v = s² mod n`

2. **Процесс аутентификации**:
   - Клиент генерирует случайное `r` и отправляет `x = r² mod n`
   - Сервер отправляет случайный вызов `e` (0 или 1)
   - Клиент отправляет `y = r * s^e mod n`
   - Сервер проверяет условие `y² ≡ x * v^e (mod n)`

## Безопасность

- Секретные ключи никогда не покидают клиентское приложение
- Все криптографические операции выполняются локально
- Используются криптографически стойкие генераторы случайных чисел
- Поддерживаются большие числа (512 бит и более)

## Требования

- Qt6 (Core, Widgets, Network)
- OpenSSL (для криптографических операций)
- C++17 совместимый компилятор
- CMake 3.16+ или qmake

## Устранение неполадок

### Проблемы с OpenSSL на macOS

Если возникают проблемы с поиском OpenSSL, установите переменные окружения:
```bash
export LDFLAGS="-L/usr/local/opt/openssl/lib"
export CPPFLAGS="-I/usr/local/opt/openssl/include"
export PKG_CONFIG_PATH="/usr/local/opt/openssl/lib/pkgconfig"
```

### Проблемы с Qt

Убедитесь, что Qt6 доступен в PATH:
```bash
export PATH="/usr/local/opt/qt@6/bin:$PATH"
```
