# 🎯 Готово! Проект Фиата-Шамира для macOS

## ✅ Что создано

Полноценное клиент-серверное приложение с авторизацией по протоколу Фиата-Шамира, готовое для сборки на вашем MacBook.

### 📁 Структура проекта
```
├── server/          # Серверное приложение (консольное)
├── client/          # Клиентское приложение (Qt GUI)
├── common/          # Общие криптографические классы
├── build_final.sh   # Скрипт сборки для вашего Qt 6.9.3
├── INSTRUCTIONS_MACOS.md  # Подробные инструкции
└── README.md        # Общая документация
```

## 🚞 Ваша проблема и решение

**Проблема**: Qt 6.9.3 установлен в `/opt/homebrew/Cellar/qt/6.9.3/`, но CMake не может его найти.

**Решение**: Используйте прямой путь к qmake при сборке.

## 🚀 Быстрый старт на вашем MacBook

Скопируйте проект на ваш MacBook и выполните:

```bash
# Перейдите в папку проекта
cd fiat-shamir-project

# Запустите сборку
./build_final.sh
```

## 📱 Использование

1. **Запуск сервера** (в первом терминале):
   ```bash
   ./server/fiat_shamir_server
   ```

2. **Запуск клиента** (во втором терминале):
   ```bash
   ./client/fiat_shamir_client
   ```

3. **Работа с приложением**:
   - Подключитесь к серверу (127.0.0.1:12345)
   - Зарегистрируйте нового пользователя
   - **ВАЖНО**: Сохраните выданный секретный ключ!
   - Войдите в систему с полученным ключом

## 🔐 Особенности реализации

- **Безопасность**: Секретные ключи никогда не передаются по сети
- **Протокол**: Полная реализация протокола Фиата-Шамира
- **GUI**: Удобный интерфейс на Qt6
- **Кроссплатформенность**: Работает на macOS, Linux, Windows
- **Криптография**: Использует OpenSSL для больших чисел

## 🛠️ Если что-то пошло не так

1. **Проверьте путь Qt**:
   ```bash
   ls /opt/homebrew/Cellar/qt/
   ```

2. **Измените путь в скрипте** (если у вас другая версия):
   ```bash
   # Откройте build_final.sh и измените:
   QT_PATH="/opt/homebrew/Cellar/qt/ВАША_ВЕРСИЯ"
   ```

3. **Проверьте OpenSSL**:
   ```bash
   brew install openssl
   ```
